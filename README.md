# chat2order_v2

라이브 방송 중 CS 직원이 주문을 직접 입력하는 경량 웹 앱 (Streamlit + Supabase).

## 접속

| 환경 | URL | 비고 |
| --- | --- | --- |
| 운영 | https://chat2order-live.up.railway.app | Railway 상시 가동 |
| 로컬 | http://localhost:8501 | 아래 "로컬 실행" 참고 |

내비게이션 바는 숨겨져 있어 URL 로 직접 접근한다.

| 페이지 | 경로 | 접근 |
| --- | --- | --- |
| 관리자 | `/` | Supabase `accounts` 계정 (이메일/비밀번호) |
| 주문 입력 | `/order?b=<방송id>&t=<직원토큰>` | 직원 토큰 링크 |
| 주문 검색 | `/search?t=<직원토큰>` | 직원 토큰 (관리자 쿠키도 허용) |

- **방송id** 는 관리자가 방송을 만들 때 발급된다. 직원 링크도 관리자 화면에서 복사한다.
- **직원 토큰** 은 계정당 1개이며 관리자 사이드바에서 재발급할 수 있다 (재발급 시 기존 링크 즉시 무효).

## 관리자 사용

1. **방송 만들기** — 방송 일시(날짜·시각)와 메모(선택)를 넣고 상품 CSV 를 올린 뒤 미리보기 → 저장.
   - 제목은 입력하지 않는다. 라방 ID 는 일정에서 `YYYYMMDD-HHMM` 으로 자동 생성되고,
     같은 일시로 이미 만든 방송이 있으면 `-v2`, `-v3` 가 붙는다 (예: `20260829-2000`).
   - 상품 CSV 는 재고 파일 `stk_forInOut_*.csv` 또는 `상품명·옵션내용·판매가` 3컬럼.
2. **링크 공유** — 저장하면 주문 입력 URL 이 표시된다. 직원에게 전달한다.
3. **마감 / 재개** — 마감하면 신규 입력·수정이 막힌다. 자동 마감은 없다.
4. **엑셀 다운로드** — 방송의 `📮 엑셀 다운로드 (우편번호 자동 보완)` 에서 "엑셀 만들기".
   - 주소는 있는데 우편번호가 빈 주문만 자동으로 한 번 조회한다:
     JUSO 직접 조회 → 실패 시 Gemini 로 도로명주소를 정제해 JUSO 재조회.
   - 빈 주문이 없으면 조회를 건너뛰고 바로 엑셀을 만든다.
   - 끝내 못 채운 주문은 본 시트에 그대로 두고 `검토필요` 시트에도 복사한다.

## 직원 사용 (주문 입력)

- 링크로 진입해 닉네임을 입력하면 그 방송의 상품 카탈로그가 로드된 폼이 뜬다.
- 상품·옵션·수량을 담고 고객 정보(수령자명·전화번호·주소 필수)를 입력한다.
- 우편번호는 `주소 검색` → JUSO 상위 후보 선택으로 도로명주소·우편번호를 채운다.
  못 찾으면 빈 값으로 두고 넘어간다 (관리자가 엑셀 추출 시 보완).
- "주문 담기" 로 여러 건을 세션의 미제출 큐에 쌓고 "전체 제출" 을 눌러야 DB 에 저장된다.
  제출 전 새로고침·탭 종료 시 미제출 주문은 사라진다.
- 같은 방송에 같은 전화번호가 이미 있으면 저장 전 경고가 뜬다 (차단은 아님, 확인 후 진행).
- 하단 "내 접수" 목록에서 본인이 넣은 최근 주문을 골라 수정·취소할 수 있다 (즉시 반영).
  타 직원 건은 읽기만 가능하다.

## 주문 검색

- `/search?t=<직원토큰>` — 방송과 무관한 상시 페이지. 브라우저 탭에 띄워 두고 쓴다.
- 소유자 계정의 **모든 방송** 주문을 수령자명·전화번호·채팅명으로 조회한다 (방송 필터 가능).
- 배송 문의 대응 등 사후 조회 용도.

## 로컬 실행

requirements 가 설치된 conda 환경 `c2o-v2` 를 활성화하고, `.env` 를 환경변수로 올린
뒤 Streamlit 을 실행한다. 앱은 `.env` 를 자동 로드하지 않고 `os.getenv` 로 읽으므로
`source` 가 필요하다.

```bash
conda activate c2o-v2
set -a && source .env && set +a
streamlit run app.py
```

실행하면 http://localhost:8501 이 열린다. 포트를 바꾸려면 `--server.port 8502` 를 뒤에
붙인다. 환경변수는 `.env.example` 참고.

## 테스트

```bash
conda activate c2o-v2
python -m pytest
```

## 배포 설정

운영 서비스 설정(빌더·시작 명령·재시작 정책·공개 도메인)은 `.railway/railway.py`
하나가 소유한다. 구 `railway.json` (Config as Code) 은 Railway 가 2026-12-01 에
지원을 끊어 제거했다.

```bash
pip install railway-sdk          # 작성/적용 전용. 런타임 의존성이 아니다
railway config plan --verbose    # 실제 환경과의 diff 미리보기
railway config apply             # 적용
```

`plan` 이 파괴적 변경(변수·도메인 삭제)을 보고하면 적용하지 말 것. 이 파일이
선언하지 않은 항목은 지워진다. Railway 에 환경변수를 새로 추가했다면
`MANAGED_VARIABLES` 에도 키를 추가해야 다음 apply 때 삭제되지 않는다.
